# Voice Scribe

Electron-приложение для записи речи с микрофона, транскрибации через Yandex SpeechKit и автокопирования результата в буфер обмена. Для коррекции и перевода используется YandexGPT. Gemini доступен как альтернативный провайдер в настройках.

## Что делает

- Записывает аудио с микрофона.
- По умолчанию отправляет запись в Yandex SpeechKit v3 напрямую в формате mono WAV (16 кГц), без Object Storage.
- В режимах коррекции и перевода обрабатывает распознанный текст через YandexGPT.
- Возвращает готовый текст и сразу копирует его в буфер.
- В Windows после новой записи также вставляет текст в активное поле другого приложения через Ctrl+V, без Enter и переключения фокуса.
- Сохраняет историю в IndexedDB.
- Поддерживает 3 режима: `general`, `corrector`, `translator`.
- Запускает и останавливает запись глобальной горячей клавишей, даже при скрытом окне.

## Глобальная горячая клавиша

Автовставка включена для новых записей: оставьте курсор в нужном поле, начните и остановите диктовку горячей клавишей. После распознавания приложение скопирует текст и отправит Ctrl+V в приложение, активное в этот момент. Не переключайте поле во время обработки, если хотите вставить результат в исходное место. Команда не нажимает Enter и не отправляет сообщение. Ручная кнопка «Копировать» и повторная обработка из истории только копируют текст.

Если активно окно Voice Scribe, меняется активное окно во время подготовки вставки, удерживаются клавиши или Windows блокирует ввод (например, в приложении, запущенном от администратора), текст остаётся в буфере. В интерфейсе появляется подсказка вставить его вручную. Автовставка поддерживается только в Windows; приложения, не поддерживающие обычный Ctrl+V, могут не принять вставку.

В Windows по умолчанию используется **Win+Alt**, без третьей клавиши. Нажмите и полностью отпустите обе клавиши, чтобы начать запись; повторите, чтобы остановить. Запись переключается только после отпускания всех клавиш сочетания, включая пользовательские сочетания в Windows. Сочетания с третьей клавишей (например, Win+Alt+R) не запускают запись через обработчик Win+Alt. Во время распознавания повторные нажатия игнорируются.

Во время записи поверх окон появляется небольшая миниатюра с красным индикатором и таймером. После остановки она показывает «Запись закончена» и состояние распознавания, затем «Готово» и скрывается через 2,5 секунды. Ошибка отображается 4,5 секунды. Миниатюра размещается в правом нижнем углу рабочего монитора, не забирает фокус и пропускает клики в приложение под ней.

Изменение: **Настройки → Горячие клавиши → нажать поле → ввести сочетание → Применить сочетание**. Например, Ctrl+Shift+R или Win+Alt+R. Если клавиши заняты другой программой, приложение сообщает об этом и оставляет прежнее сочетание. Выбор сохраняется между запусками отдельно от API-настроек.

Крестик скрывает окно в системный трей. Приложение продолжает работать, записывать и копировать результат в буфер обмена без перехвата фокуса. Красный значок в трее означает запись. Двойной щелчок по значку открывает окно; контекстное меню позволяет переключить запись или полностью выйти. Горячая клавиша действует, пока приложение запущено. Разрешение на микрофон нужно выдать при первом использовании.

Срабатывание при отпускании в Windows реализовано через скрытый локальный обработчик Windows PowerShell и Win32. Он передаёт только сигнал переключения записи, не сохраняет нажатия клавиш и завершается вместе с приложением. Обработчик необходим и для пользовательских сочетаний; если его запуск запрещён системной политикой, запись доступна кнопкой и локальным пробелом. На других ОС исходное глобальное сочетание — Ctrl+Alt+R (на нажатие).

Пробел остаётся локальной клавишей переключения в основном окне. Он не срабатывает в полях ввода, открытых настройках и истории. Проверки: `node --test services/*.test.mjs electron/*.test.cjs`.

При выборе Gemini в настройках можно ввести `gemini-3.5-transcribe`: эта модель использует Interactions API
и режим smart для транскрибации записанного аудио. В режимах `corrector` и `translator`
полученный текст дополнительно обрабатывается через `gemini-2.5-flash` (отдельный API-запрос).
Потоковая модель `gemini-3.5-transcribe-live` в этом приложении не поддерживается.

## Быстрый старт

Требования: Node.js 18+.

1. Установить зависимости.

```bash
npm install
```

2. Создать файл `.env` в корне.

```env
YANDEX_API_KEY=your_service_account_api_key
YANDEX_FOLDER_ID=your_folder_id
YANDEX_GPT_MODEL=yandexgpt/latest
```

Либо откройте **Настройки → API Ключи → Yandex Cloud** и введите API-ключ и ID каталога.
Пустое поле ключа при сохранении оставляет ранее настроенный ключ. Настройки хранятся локально в профиле приложения; поле ключа при открытии всегда пустое.
В установленной Electron-версии `.env` или `.env.local` должен находиться рядом с исполняемым файлом.
В браузерном dev-режиме используйте поля настроек или переменные `VITE_YANDEX_API_KEY`, `VITE_YANDEX_FOLDER_ID`, `VITE_YANDEX_GPT_MODEL`; для работы без ограничений CORS запускайте Electron.

Сервисному аккаунту нужны роли `ai.speechkit-stt.user` и `ai.languageModels.user` на каталог.
Для API-ключа разрешите области `yc.ai.speechkitStt.execute` и `yc.ai.languageModels.execute`.
Статус «Настроен» означает, что заполнены настройки; доступ к API проверяется на реальной записи, без платных фоновых запросов.
Распознавание Yandex настроено на русский язык (`ru-RU`): SpeechKit требует один разрешённый язык для нормализации, включая пунктуацию и заглавные буквы. Обычный режим возвращает нормализованный результат SpeechKit без дополнительного запроса к YandexGPT, сокращая ожидание и исключая перефразирование на этапе GPT. `corrector` дополнительно вызывает YandexGPT для оформления в деловом стиле, `translator` — для перевода на английский.
Лимит WAV — 60 МБ, ожидание распознавания — до 600 опросов с интервалом 1 секунда плюс время HTTP-запросов. При таймауте сообщение содержит ID операции для проверки в Yandex Cloud.
Записи автоматически не отправляются другому провайдеру при ошибке. Для ручного возврата к Gemini выберите его в настройках и укажите `GEMINI_API_KEY`.

Документация: [SpeechKit v3](https://yandex.cloud/ru/docs/speechkit/stt-v3/api-ref/AsyncRecognizer/recognizeFile), [YandexGPT](https://yandex.cloud/ru/docs/ai-studio/text-generation/api-ref/TextGeneration/completion).

3. Запуск.

```bash
# frontend
npm run dev

# frontend + electron
npm run electron:dev
```

## Переменные окружения

- `YANDEX_API_KEY` — API-ключ сервисного аккаунта Yandex Cloud.
- `YANDEX_FOLDER_ID` — ID каталога Yandex Cloud.
- `YANDEX_GPT_MODEL` — модель для коррекции и перевода, по умолчанию `yandexgpt/latest`.
- `GEMINI_API_KEY` - основной ключ Gemini.
- `VITE_GEMINI_API_KEY` - fallback для renderer.

## Архитектура

- `electron/main.cjs` - окно, IPC, загрузка env.
- `electron/preload.cjs` - безопасный мост `window.electronAPI`.
- `App.tsx` - orchestration UI, запись, hotkeys, режимы.
- `services/geminiService.ts` - транскрибация и health-check Gemini.
- `services/transcriptionService.ts` — выбор провайдера (по умолчанию Yandex).
- `services/yandexService.ts` — SpeechKit v3 и YandexGPT, обработка ошибок и результатов.
- `services/yandexAudio.ts` — декодирование записи и преобразование в mono WAV 16 кГц.
- `services/yandexConfig.ts` — настройки Yandex из профиля и окружения.
- `services/storageService.ts` - история записей (IndexedDB).
- `services/quotaService.ts` - локальный учет дневной квоты.

Поток данных:

`Microphone -> MediaRecorder -> Blob -> WAV -> SpeechKit -> [YandexGPT] -> Text -> Clipboard + IndexedDB`

Проверки сервисов: `node --test services/*.test.mjs`.
